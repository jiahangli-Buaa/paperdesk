# 安装与使用

## 安装

- Apple Silicon Mac（M 系列芯片）：打开 `release/macos-arm64/` 中的 DMG，将 Paperdesk 拖入“应用程序”。支持 macOS 14 及以上。
- Windows Intel／AMD 64 位：推荐运行 `Paperdesk-1.0-Windows-Offline.exe`，按安装向导选择目录。也可使用体积较小的在线安装包 `Paperdesk-1.0-Windows.exe`。正式支持基线为 Windows 11。

Windows 离线安装包已包含投稿读取组件，安装和首次打开无需下载组件。在线安装包在安装过程中下载；Mac 在首次打开时下载。使用在线安装包遇到下载一直停在 0% 时，可退出安装程序，改用离线安装包。无需自行安装 Python 或 Node.js，读取期刊网站的投稿状态仍需联网。

## 开始使用

1. 填写你的姓名、英文姓名或其他署名。这些设置用于统计自己的第一作者和通讯作者论文。
2. 添加期刊和投稿账号，填写实际使用的登录入口与登录方式。
3. 添加要跟踪的稿件，完整英文题目用于匹配网站记录。
4. 点击“刷新审稿中”读取最新状态。需要人工登录验证时，使用对应账号的验证入口。

每个账号保留独立会话；同一期刊可以添加多个账号。只跟踪主动添加的稿件。

新用户自行填写期刊和投稿网址。ScholarOne、Editorial Manager、PaperCept 按网址识别；OJS 3.4 试用路径需手动选择该平台并填写 `/index.php/<journal>/login` 形式的完整网址。遇到验证码时点击“打开验证窗口”完成网站验证。支持范围见 [平台适配范围](平台适配范围.md)。

## 刷新与提醒

在“设置”中选择每天三个刷新时间，以及状态变化、返修截止的通知选项。“个人与数据”中可修改时区。

审稿中范围包含已投稿、编辑处理中、外审中、等待决定和待确认；待返修及已结束稿件保留历史并跳过例行刷新。修回后，将记录改回审稿中即可恢复读取。

默认关闭窗口后继续后台运行。从 Mac 菜单栏或 Windows 托盘可重新打开。选择“退出 Paperdesk”会停止后台任务。电脑休眠和关机期间暂停读取，恢复运行后合并处理错过的刷新时段。

## 旧版迁移和备份

Mac 用户可在首次引导或“个人与数据”中选择“导入旧版 Mac 数据”。应用读取原个人版数据库的副本，原版数据保留。导入后补充自己的署名，并在账号管理中重新保存密码。

“导出备份”生成 `.paperdesk` 文件，包含稿件、状态历史、背景和设置。密码及浏览器会话保留在本机；从备份恢复或换电脑后重新连接账号。

恢复前，当前数据库自动备份到应用数据目录下的 `backups/`。应用升级会保留用户数据。

## 更新

菜单和“个人与数据”均提供“检查更新”。发现新版本后，可从此入口下载新版安装包并覆盖安装。稿件和设置会保留。

## 数据位置

在“个人与数据”中点击“打开数据目录”即可访问备份和日志。

- Mac：`~/Library/Application Support/PaperdeskDesktop/`
- Windows：`%LOCALAPPDATA%\Paperdesk\`

旧 Mac 个人版继续使用原有 `Paperdesk/` 数据目录，两者独立。
