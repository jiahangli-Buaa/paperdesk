# Paperdesk 使用许可

Paperdesk 采用 [PolyForm Noncommercial 1.0.0](../LICENSE)，公开源码，面向科研与其他获准的非商业用途免费提供。本页是便于阅读的说明，完整许可条款以 `LICENSE` 为准。

## 免费使用范围

- 为公共知识开展、无预期商业应用的个人科研、实验、学习和测试。
- 教育机构、公共科研机构，以及许可列明的其他非商业机构的使用。
- 在许可允许的用途内修改软件、分享原版或修改版，并保留许可及要求保留的版权声明。

## 商业授权

该许可不授予商业使用权。收费销售原版或修改版、改名包装后销售、将软件用于商业产品或提供商业服务，需要取得权利人的单独授权。更改软件名称、界面或部分代码不会自动获得商业使用权。

商业授权需求可通过 [GitHub Issue](https://github.com/jiahangli-Buaa/paperdesk/issues) 联系维护者，简要说明拟开展的用途。

## 适用范围

本许可适用于 Paperdesk 自有代码。Electron、Node.js、Python、Playwright 等第三方组件继续遵循各自许可，见 [第三方组件说明](第三方组件说明.md)。
