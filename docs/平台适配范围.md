# 支持的投稿平台

新用户自行填写期刊名称、投稿网址和账号。Paperdesk 根据平台和登录方式选择读取器；期刊列表显示自己添加的条目。

| 平台 | 投稿入口 | 登录方式 |
| --- | --- | --- |
| ScholarOne | `mc*.manuscriptcentral.com/<journal>` | 期刊账号与密码 |
| Editorial Manager | `www.editorialmanager.com/<journal>` 及标准登录路径 | 期刊账号、ORCID 或 Elsevier，按期刊实际提供的方式选择 |
| PaperCept | `*.paperplaza.net` 或 `*.papercept.net` 的 `/journals/<journal>/scripts/login.pl` | PIN／登录名与密码 |
| Open Journal Systems 3.4（试用） | `/index.php/<journal>/login` 形式的标准入口，手动选择 OJS 3.4 平台 | 期刊账号与密码 |

需要验证码或人工登录时，点击“打开验证窗口”完成网站步骤。网站暂时无法连接时，可稍后再次刷新。

Editorial Manager 按表格标题读取稿件编号、题目、状态和日期，支持对应的返修队列。OJS 3.4 读取作者稿件列表与归档，保留页面提供的原始状态；3.5 和自定义路由尚未接入。

其他平台可手动管理稿件。Springer Nature Snapp、Wiley Research Exchange、Taylor & Francis Submission Portal、eJournalPress、MDPI SuSy 和 Frontiers 暂未提供自动读取。
