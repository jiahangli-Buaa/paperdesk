# 第三方组件

Paperdesk 随安装包分发 Electron（MIT）、Node.js（MIT 与其第三方许可）、CPython（PSF）、Playwright（Apache-2.0）、tzdata，并在安装或首次启动时下载配套 Chromium 和 Firefox 浏览器。

各组件的 LICENSE、LICENSE.txt、COPYING 或其他原始许可文件保留在对应运行目录中。Chromium 和 Firefox 的第三方许可沿用原始发行包。

Mac Python 运行时来自 Astral python-build-standalone 的官方构建；Windows Python 来自 python.org 官方嵌入式发行包。浏览器版本由锁定的 Playwright 版本选择。具体版本见 runtime/runtime-manifest.json。

本产品未获得期刊投稿平台的官方授权或背书；支持范围见平台说明。
