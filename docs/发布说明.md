# Paperdesk 1.0

[下载软件](https://github.com/jiahangli-Buaa/paperdesk/releases/latest)

Paperdesk 是一个集中管理论文投稿进度的桌面工作台，支持 Apple Silicon Mac 与 Windows x64。

## 本版功能

- 多期刊、多账号管理与稿件总览。
- 按第一作者、通讯作者、期刊和状态筛选。
- 投稿平台状态读取、状态变化历史和返修提醒。
- 个人署名、时区、主题及背景设置。
- 托盘／菜单栏、后台驻留与可选开机启动。
- 本地备份恢复与系统凭据存储。

## 安装

- **Mac**：下载 `Paperdesk-1.0-Mac.dmg`，打开后将 Paperdesk 拖入“应用程序”。首次启动自动下载投稿读取组件。
- **Windows**：下载 `Paperdesk-1.0-Windows.exe`，按向导安装。组件在安装过程中自动下载，完成后即可打开。

安装和首次准备时请保持网络连接。已下载组件会在后续启动与升级时复用。

新用户自行添加期刊和投稿账号。支持的平台与登录方式见 [平台适配范围](平台适配范围.md)，日常操作见 [使用指南](使用指南.md)。
