# Paperdesk 1.1

[下载软件](https://github.com/jiahangli-Buaa/paperdesk/releases/latest)

Paperdesk 是一个集中管理论文投稿进度的桌面工作台，支持 Apple Silicon Mac 与 Windows x64。

## 本版更新

- 扩充投稿日期和状态日期格式；个别日期无法识别时继续同步可识别的信息，保留已有投稿日期。
- 改进 Editorial Manager 登录表单、作者首页及稿件列表的识别，支持会话恢复和会话过期后的重新登录。
- 新增期刊全名、简称编辑入口。
- 新增账号和期刊删除功能，确认后清理关联的本地稿件、历史、提醒、密码和登录会话。

从 1.0 升级可直接覆盖安装，已有稿件和设置继续保留。

## 安装

- **Mac**：下载 `Paperdesk-1.1-Mac.dmg`，打开后将 Paperdesk 拖入“应用程序”。投稿读取组件已包含在包内。
- **Windows**：下载 `Paperdesk-1.1-Windows-Offline.exe`，按向导安装。投稿读取组件已包含在包内，安装和首次启动无需下载组件。

Mac 和 Windows 均为完整离线安装包，安装和首次启动无需下载组件。读取期刊网站的投稿状态仍需联网。

新用户自行添加期刊和投稿账号。支持的平台与登录方式见 [平台适配范围](平台适配范围.md)，日常操作见 [使用指南](使用指南.md)。
