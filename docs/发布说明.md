# Paperdesk 1.0

[下载软件](https://github.com/jiahangli-Buaa/paperdesk/releases/latest)

Paperdesk 是一个集中管理论文投稿进度的桌面工作台，支持 Apple Silicon Mac 与 Windows x64。

## 本版功能

- 多期刊、多账号管理与稿件总览。
- 按第一作者、通讯作者、期刊和状态筛选。
- 投稿平台状态读取、状态变化历史和返修提醒。
- 个人署名、时区、主题及背景设置。
- 托盘／菜单栏、后台驻留与可选开机启动。
- 本地备份恢复与系统凭据存储。

## 安装

- **Mac**：下载 `Paperdesk-1.0-Mac.dmg`，打开后将 Paperdesk 拖入“应用程序”。首次启动自动下载投稿读取组件。
- **Windows 离线安装包（推荐）**：下载 `Paperdesk-1.0-Windows-Offline.exe`，按向导安装。投稿读取组件已包含在包内，安装和首次启动无需下载组件。
- **Windows 在线安装包**：下载 `Paperdesk-1.0-Windows.exe`，按向导安装。安装包较小，组件在安装过程中自动下载。

Windows 两种安装包功能相同，版本均为 1.0。在线安装包与 Mac 首次准备组件时请保持网络连接；组件准备完成后会复用。读取期刊网站的投稿状态仍需联网。

新用户自行添加期刊和投稿账号。支持的平台与登录方式见 [平台适配范围](平台适配范围.md)，日常操作见 [使用指南](使用指南.md)。
